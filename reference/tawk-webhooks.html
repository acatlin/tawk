Events and fields

chat:startFirst message by visitor or agent (not whispers or trigger notifications)chatId, time, domain, referrer, message{ text, type: msg|file|webrtc-call, sender{ type: agent|visitor|system } }, visitor{ name, email?, city, country }, property{ id, name }

ticket:createNew tickettime, property, requester{ name, email, type? }, ticket{ id, humanId, subject, message }

sender.t: a agent, v visitor, s system. No per-message event exists. Custom attributes and tags are not in any payload.

Signature

  • Header X-Tawk-Signature = HMAC-SHA1(secret, raw body), hex.
  • Verify the raw bytes (await request.text()) before JSON.parse; compare with crypto.timingSafeEqual after a length check.
import { createHmac, timingSafeEqual } from "node:crypto";
const expected = Buffer.from(createHmac("sha1", secret).update(rawBody).digest("hex"), "hex");
const given = Buffer.from(header ?? "", "hex");
const ok = given.length === expected.length && given.length > 0 && timingSafeEqual(given, expected);

Retries

  • Non-2XX, or no response within 30 s → retried for up to 12 hours.
  • X-Hook-Event-Id is constant across retries → idempotency key in a shared store.
  • Return 2XX for events you ignore. Respond first; slow work after (waitUntil from @vercel/functions, or a queue).

Vercel handler (examples/api/tawk-webhook.ts)

export async function POST(request: Request) {
  const rawBody = await request.text();
  const result = await handleTawkWebhook(
    { rawBody, signature: request.headers.get("x-tawk-signature"), eventId: request.headers.get("x-hook-event-id") },
    { secret: process.env.TAWK_WEBHOOK_SECRET ?? "", store },
  );
  return new Response(result.body, { status: result.status });
}

Order inside handleTawkWebhook: secret present → verify (401) → parse (400) → dedupe (200 duplicate) → store → side effects → 200 ok <event>.
