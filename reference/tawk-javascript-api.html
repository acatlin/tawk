Secure mode

  • “The hash is server side generated HMAC using SHA256, the user’s email and your site’s API key.” For login: userId + key.tawk.to JavaScript API reference Help articles say “user ID” for both: test once against your dashboard.
  • Key: Administration → Overview → JavaScript API → enable Secure Mode → copy.tawk.to Help: generating a hash
  • Node: createHmac("sha256", key).update(identifier).digest("hex") (see examples/src/tawk-secure-mode.ts).
  • Mismatch: details silently not updated; login logs 401 in the console.

Handoff recipe (lesson 2)

Tawk_API.onLoad = async () => {
  const { userId, hash } = await fetch('/api/tawk-identity').then(r => r.json());
  Tawk_API.login({ userId, hash }, log);
  Tawk_API.setAttributes({ 'bot-last-reason': reason }, log);
  Tawk_API.addTags(['bot-handoff'], log);
  Tawk_API.addEvent('bot-handoff', { reason }, log);
  Tawk_API.setChatInputMessage(summary, log);
  Tawk_API.maximize();
};
