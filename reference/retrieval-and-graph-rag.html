FAQ tier dials (lesson 4)

  • Scores are 0..1 for exact, jaccard, tfidf; one threshold works across strategies.
  • threshold: minimum top score. margin: minimum gap to the runner-up (catches sibling entries).
  • Tune order: zero wrong → fewest missed → add variants from real transcripts.
  • Step up to BM25 (MiniSearch, BM25+ with fuzzy/prefix) past a few hundred entries; embeddings after that (Anthropic recommends Voyage AI; Anthropic has no embedding model).MiniSearchClaude docs: Embeddings
  • Precedent: Rasa retrieval intents + rules; Dialogflow CX generative fallback only on no-match.Rasa: Chitchat and FAQsDialogflow CX: Generative fallback

Citations request shape (lesson 5)

{ "type": "document",
  "source": { "type": "text", "media_type": "text/plain", "data": "chunk text" },
  "title": "Support channels",
  "context": "Source URL: https://help.harbor.example/support",   // read, never cited
  "citations": { "enabled": true } }
  • Enable on all or none of the documents in a request. All active models support citations.Claude docs: Citations
  • Plain text and PDF are chunked into sentences; custom-content documents are cited block by block with no re-chunking.
  • Response: several text blocks; cited ones carry citations[] with cited_text, document_index, document_title, and char_location (0-indexed start, exclusive end) / page_location (1-indexed) / content_block_location.
  • cited_text is not billed as output tokens, nor as input when passed back.
  • Incompatible with structured outputs (output_config.format): 400.

Prompt caching facts

  • cache_control: { type: "ephemeral" } on a block, or top-level for automatic placement; up to 4 breakpoints; prefix order is tools → system → messages.
  • Minimum cacheable prefix: 512 tokens on Claude 5.x models (Opus 5.5, Sonnet 5.5, Haiku 5.5, Fable 5.1); 1,024–4,096 on older models. Shorter prefixes are silently not cached.
  • TTL 5 minutes by default, refreshed on every hit; ttl: "1h" available. Writes cost 1.25× (5 min) or 2× (1 h); reads 0.1× (0.05× on Opus 5.5 / Sonnet 5.5).
  • Verify with usage.cache_read_input_tokens.Claude docs: Prompt caching

Retrieval quality levers (when you move past the FAQ)

  • Contextual retrieval: prepend a 50–100 token, document-aware context to each chunk before embedding and BM25-indexing. Anthropic measured top-20 retrieval failure falling from 5.7% to 3.7% (embeddings), 2.9% (+BM25), 1.9% (+reranking). Below ~200k tokens, skip retrieval and cache the whole corpus.Anthropic: Contextual Retrieval
  • Summary indexing + reranking: Anthropic’s RAG cookbook raised end-to-end accuracy from 71% to 81% on its own docs.Claude cookbook: RAG guide
  • Stores reachable from Vercel: Postgres + pgvector (Neon, Supabase; <=> is cosine distance, HNSW index), Upstash Vector (REST, hybrid dense+BM25), Pinecone (Node ≥ 22).Neon: pgvectorUpstash VectorPinecone Node SDK
  • Vercel AI SDK: embed, embedMany, cosineSimilarity from ai; the Anthropic provider exposes webFetch_20260318/webSearch_20260318 and cacheControl, but no embedding model.AI SDK: Anthropic provider
