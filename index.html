tawk.to for your Claude chatbot

Eight short lessons, each with one tangible win, for a developer shipping a first chatbot integration: tawk.to as the human channel, Claude on Vercel as the brain, answers from a FAQ first and from one or two approved sources only, on the web and on Android.

How this course works

Read a lesson (20–30 minutes), do the lab, take the quiz from memory, then come back in a few days for the spaced review. Every claim links to the page it was verified against. The code you see is tested: cd examples && npm install && npm test. The agent that built the course is your tutor: open a terminal in this folder, run claude, and ask.

The premise

tawk.to does not let an outside system post messages into its chat widget, and its staff have said so repeatedly (lesson 1 has the citations). So the course teaches the pattern that survives that fact: your bot is the front door; tawk.to is the human channel. Lessons 2 and 3 build the bridge to tawk.to in both directions, lessons 4 to 6 build the answer engine, lesson 7 explains when a graph index would help, and lesson 8 takes it to Android.

Lessons

    Reference sheets

    • tawk.to JavaScript API: settings, methods, callbacks, limits, secure mode.
    • tawk.to webhooks: events, payload fields, signature, retries, handler.
    • Answer pipeline: flow, shapes, reason codes, handoff policy, grounding prompt.
    • Retrieval & Graph RAG: citations, domain rules, caching, decision table.
    • Glossary: the course’s canonical vocabulary.

    The companion code

    The examples/ folder is a small TypeScript package with the modules the lessons quote and a test suite that pins their behaviour: FAQ matching, the allow-list guard, grounded answers with Claude citations, the pipeline, secure-mode hashing, webhook verification, and the graph prototype. Two scripts send a grounded question to Claude and a signed test webhook to any URL.

    Workspace files

    MISSION.md (why), RESOURCES.md (trusted sources and communities), GLOSSARY.md, NOTES.md (teaching notes), learning-records/ (what has been established so far). They steer future sessions; read them before asking for lesson nine.
